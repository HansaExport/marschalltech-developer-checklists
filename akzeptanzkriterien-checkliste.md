# Akzeptanzkriterien – Schnellcheck

Eine kompakte Checkliste für klare und überprüfbare Akzeptanzkriterien in Softwaretickets.

## Schnellcheck

- [ ] Das Ziel des Tickets ist verständlich.
- [ ] Die Kriterien beschreiben beobachtbares Verhalten.
- [ ] Jedes Kriterium ist eindeutig überprüfbar.
- [ ] Wichtige Randfälle sind berücksichtigt.
- [ ] Relevante Fehlerfälle sind beschrieben.
- [ ] Sicherheits-, Rollen- oder Datenanforderungen sind sichtbar, wenn sie relevant sind.
- [ ] Die Kriterien beschreiben primär das gewünschte Ergebnis statt die technische Umsetzung.
- [ ] Es gibt keine versteckten Zusatzanforderungen.
- [ ] Ein Reviewer kann später nachvollziehen, wann die Aufgabe erfüllt ist.

## Beispiel

Statt:

> Das Formular soll gut funktionieren.

Besser:

> Wenn ein Pflichtfeld leer ist, wird das Formular nicht abgesendet und das betroffene Feld erhält eine verständliche Fehlermeldung.

## Grundsatz

Akzeptanzkriterien schaffen ein gemeinsames Verständnis davon, welches Verhalten erwartet wird. Sie sollen Orientierung geben, nicht die technische Lösung unnötig vorwegnehmen.
