# MarschallTech Developer Checklists

Praktische Checklisten und Vorlagen für kleine Softwareteams – kompakt, technologieunabhängig und direkt einsetzbar.

Dieses Repository bündelt frei nutzbare Arbeitsgrundlagen für typische Situationen im Softwarealltag:

- [Pull-Request-Checkliste](pull-request-checkliste.md)
- [Code-Review-Checkliste](code-review-checkliste.md)
- [Release-Checkliste](release-checkliste.md)
- [Definition of Done](definition-of-done.md)
- [Bug-Report-Template](bug-report-template.md)
- [ADR-Vorlage – Architecture Decision Record](adr-vorlage.md)
- [Akzeptanzkriterien – Schnellcheck](akzeptanzkriterien-checkliste.md)

Die Vorlagen sind bewusst schlank gehalten. Sie sollen Teams einen guten Ausgangspunkt geben und können an eigene Prozesse, Tools und Qualitätsanforderungen angepasst werden.

## Für wen?

Für Entwicklerinnen und Entwickler, Tech Leads und kleine Softwareteams, die Tickets, Reviews, Releases und technische Entscheidungen klarer und verlässlicher gestalten möchten.

## Mehr Vorlagen für den Teamalltag
