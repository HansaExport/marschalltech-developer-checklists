# Bug Report Template

Eine kompakte Vorlage für reproduzierbare und nachvollziehbare Fehlerberichte.

## Vorlage

**Titel:**
Kurze, konkrete Beschreibung des Problems.

**Umgebung:**
- Anwendung / Version:
- Browser / Betriebssystem / Gerät:
- Umgebung / Mandant / relevante Konfiguration:

**Schritte zur Reproduktion:**
1. …
2. …
3. …

**Erwartetes Verhalten:**
…

**Tatsächliches Verhalten:**
…

**Häufigkeit:**
Immer / häufig / gelegentlich / einmalig

**Auswirkung:**
Welche Funktion ist betroffen? Gibt es einen Workaround?

**Belege:**
Screenshots, Fehlermeldungen, Logs oder Request-IDs – sensible Daten vorher entfernen.

## Schnellcheck

- [ ] Fehler ist reproduzierbar beschrieben.
- [ ] Umgebung und Version sind genannt.
- [ ] Soll- und Ist-Verhalten sind getrennt beschrieben.
- [ ] Häufigkeit und Auswirkungen sind erkennbar.
- [ ] Relevante Belege sind ergänzt.
- [ ] Vermutungen sind als Vermutungen gekennzeichnet.
